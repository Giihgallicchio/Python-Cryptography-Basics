# 🔐 PROJETO — CRIPTOGRAFIA

## 📌 Tema do Projeto
### Exercício Introdutório de Lógica e Criptografia em Python

---

## 📝 Sobre o Projeto

Este projeto representa o meu contato inicial com os fundamentos de **Segurança da Informação** e **Criptografia**. Desenvolvido originalmente como uma atividade acadêmica na **Faculdade Senac**, o exercício utiliza a linguagem Python para demonstrar de forma prática como dados textuais podem ser codificados, protegidos e posteriormente decodificados.

Por ter um caráter puramente didático e introdutório, o foco principal foi aplicar estruturas condicionais e de repetição na transformação e manipulação de fluxos de strings.

---

## 🎯 Objetivos do Exercício

* 🧠 **Fundamentos:** Compreender os conceitos iniciais de chaves, cifras e codificação de dados.
* 🛠️ **Prática em Python:** Aplicar lógica de programação em um contexto focado em segurança de dados.
* 🧵 **Manipulação de Strings:** Trabalhar com iteração, índices e vetores de caracteres para mascarar textos.
* 🧩 **Raciocínio Lógico:** Desenvolver algoritmos reversíveis (capazes de criptografar e descriptografar a mesma informação).

---

## 🧠 Conceitos e Aprendizados Adquiridos

Durante a codificação do script no ambiente em nuvem, foram consolidados os seguintes tópicos:
* **Algoritmos de Substituição/Transposição:** Entendimento de como caracteres mudam de posição ou de valor com base em uma regra lógica.
* **Transformação de Dados:** Processos de codificação estruturada.
* **Segurança na Prática:** Noções básicas de integridade de dados e confidencialidade.
